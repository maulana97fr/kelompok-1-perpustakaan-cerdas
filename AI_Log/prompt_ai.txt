[AI Solusi & Implementasi]

  * anggota yang memesan lebih dulu mendapatkan giliran lebih dulu.

## SESI 3: ANALISIS BIG-O QUEUE

[Context / Problem]

* Diperlukan analisis kompleksitas waktu dan ruang pada Queue untuk BAB Analisis Big-O.
* Analisis digunakan sebagai bagian penilaian project.

[User Prompt]

* "jelaskan Big-O queue"
* "buatkan analisis kompleksitas"
* "buatkan tabel Big-O"

[AI Solusi & Implementasi]

* Melakukan analisis kompleksitas Queue:

  1. enqueue()

     * Time Complexity  : O(1)
     * Space Complexity : O(n)

  2. dequeue()

     * Time Complexity  : O(1)
     * Space Complexity : O(n)

  3. tampil()

     * Time Complexity  : O(n)
     * Space Complexity : O(n)

  4. batal_pesan()

     * Time Complexity  : O(n)
     * Space Complexity : O(n)

* Menjelaskan alasan kompleksitas:

  * enqueue dan dequeue langsung mengakses tail/head.
  * traversal membutuhkan pembacaan seluruh node.
  * batal_pesan melakukan traversal pencarian data.
